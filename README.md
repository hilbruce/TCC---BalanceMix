# TCC---BalanceMix
Este trabalho apresenta o desenvolvimento do aplicativo móvel BalanceMix, uma solução digital projetada para auxiliar na formulação de rações balanceadas para diferentes espécies animais, operando totalmente de forma offline. 
Utilizando como método de cálculo o Quadrado de Pearson, o aplicativo BalanceMix realiza operações matemáticas que visam o balanceamento dos insumos para ração animal com base na necessidade de Proteína Bruta (PB). 
O projeto tem como finalidade democratizar o acesso a uma ferramenta simples e funcional, promovendo maior autonomia ao agricultor no manejo alimentar dos animais, contribuindo para a melhoria da produtividade, redução de custos e sustentabilidade das atividades rurais.
